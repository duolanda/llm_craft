## 采用结果与限制

这轮实验曾采用候选 10，保持 user 消息角色、原 system prompt、会话历史、工具定义、温度和 token 上限不变。所有文字调整只发生在末尾复盘指令中，保存路径没有添加截断或关键词过滤。

最终三份正文平均 129 字，原指令两份有效正文平均 3330 字。三份完整输出与实际指令已直接列在本文开头，便于对照审阅。

长度仅是辅助指标。先前因输出简短、有条件和取舍而采用候选 10，但对具体单位类别、建筑数量和位置安排的验收偏宽。这些内容违反了指令中已经写明的限制，不能仅因附带条件就认定通过。目前能确认的是篇幅压缩有效；避免过度具体仍未完全达到要求。

本轮只验证同一个 `mimo-v2.5` 配置和这一局的红方上下文；没有证明跨模型、跨对局都稳定，也没有通过新对局验证这些具体策略建议能提高胜率。连续复测结果作为当前指令的验收样本保留，下一次发现反例应增加固定样本继续比较。

实现验证：服务端 43 个测试文件通过（450 项通过、9 项原有跳过）；采集相关的 23 项回归另行通过。回归检验了完整前缀与工具保留、采集回调隔离、失败后不污染历史和网络重试只采集一次，没有为提示词措辞编写固定字符串测试。服务端和独立评估脚本均通过严格类型检查。
