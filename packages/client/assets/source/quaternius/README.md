# Third-party source assets

The production battlefield models use two source files from Quaternius:

- `AnimatedTanks-Tank4.blend` from [Animated Tanks](https://quaternius.com/packs/animatedtanks.html)
- `AnimatedMen-MaleLongSleeve.blend` from [Animated Men](https://quaternius.com/packs/animatedmen.html)

Both source pages identify the packs as CC0. The included `LICENSE.txt` is the
license file distributed with the Animated Tanks pack. The generated game GLBs
are modified derivatives: geometry is posed, rescaled, re-materialed, combined
with original LLMCraft armor/weapons, and exported with generated PBR textures.
