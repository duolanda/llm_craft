# Battlefield texture sources

The `terrain_ph_*` files are the Poly Haven **Aerial Grass Rock** texture.
The `road_ph_*` files are the Poly Haven **Dirt Aerial 02** texture.

The `terrain_industrial_*` files are a project-specific, AI-generated modern
military-industrial terrain material. The albedo was generated as a seamless
top-down texture; its normal and roughness maps are derived locally with
`packages/client/scripts/prepare-industrial-terrain-textures.py`.

- Source: https://polyhaven.com/a/aerial_grass_rock
- Source: https://polyhaven.com/a/dirt_aerial_02
- License: CC0
- Resolution: 2K JPG
- Maps: Diffuse, OpenGL Normal, Roughness
